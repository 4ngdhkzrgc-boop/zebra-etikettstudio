1. Skriver

ZD421 / ZPL
Se skriverinformasjon
Når skriverinformasjon er importert, kan du velge skriveren her.

Skriverlisten lagres bare i denne nettleseren. Rapporterte etikettmål er skriverinnstillinger og kan avvike fra papiret som er satt inn.

Du kan også skrive inn IP-adressen manuelt. Velg en skriver i listen over for å fylle ut IP-adressen automatisk.

Søket prøver HTTP på adresser fra 172.30.99.1 til 172.30.99.254. Det er ikke et ICMP-ping, og nettleseren kan blokkere forespørslene. En IP som svarer, er ikke nødvendigvis en skriver. Bruk bare skanning der du har tillatelse.

Ingen søk utført.
Hent skrivernavn og etikettinnstillinger fra Windows (anbefalt)

Nettleseren kan vanligvis ikke lese skriverdata direkte. Denne PowerShell-koden søker på 172.30.99.1–254 og spør Zebra-skriverne på port 9100 om navn, modell, DPI, konfigurert utskriftsbredde og etikettlengde. Spørringene er skrivebeskyttet og endrer ikke skriverinnstillinger. Bruk bare på nettverk der du har tillatelse. Skriverporten må være tilgjengelig fra PC-en.

1. Åpne PowerShell på en Windows-PC i samme bedriftsnettverk. 2. Lim inn koden og kjør den. 3. Resultatene kopieres automatisk til utklippstavlen. 4. Lim dem inn under og velg «Importer skriverinfo». Noen skrivere kan mangle enkelte verdier.

Vis PowerShell-koden hvis kopiering ikke fungerer

Om etikettmål: Tallene er skriverens innstilte utskriftsbredde og etikettlengde, ikke nødvendigvis størrelsen på etiketten som faktisk er satt inn. Den siste jobben kan ha endret dem.

4. Skriv ut

Direkte til skriver

Velg alle skriverne som skal få etiketten. Hver skriver får riktig DPI og etikettformat.

Vanlig utskrift bruker den tidligere fungerende HTML-POST-metoden. For flere skrivere prøver nettleseren å sende til alle valgte adresser uten PowerShell.

1 etikett til én skriver.

Viktig: Nettleseren kan blokkere lokal HTTP i skjulte rammer. «Forsøkt sendt» betyr ikke at skriveren mottok jobben. Sjekk etiketten før du prøver reserveknappen, ellers kan du få duplikater.

Utskrift: Én skriver bruker den gamle HTML-POST-metoden. Ved flere skrivere sendes separate nettleserforespørsler som kan bli blokkert av sikkerhetsregler. Appen kan ikke bekrefte fysisk utskrift. Kontroller resultatet før et nytt forsøk.
