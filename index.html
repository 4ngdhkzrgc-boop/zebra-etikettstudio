🏷️ Etikettstudio

Lag etiketter, last opp bilder og skriv ut direkte til Zebra-skriveren din. Fungerer både på datamaskin og mobil.

1. Skriver

ZD421 / ZPL
Når skriverinformasjon er importert, kan du velge skriveren her.

Skriverlisten lagres bare i denne nettleseren. Rapporterte etikettmål er skriverinnstillinger og kan avvike fra papiret som er satt inn.

Du kan også skrive inn IP-adressen manuelt. Velg en skriver i listen over for å fylle ut IP-adressen automatisk.

Søket prøver HTTP på adresser fra 172.30.99.1 til 172.30.99.254. Det er ikke et ICMP-ping, og nettleseren kan blokkere forespørslene. En IP som svarer, er ikke nødvendigvis en skriver. Bruk bare skanning der du har tillatelse.

Ingen søk utført.
Hent skrivernavn og etikettinnstillinger fra Windows (anbefalt)

Nettleseren kan vanligvis ikke lese skriverdata direkte. Denne PowerShell-koden søker på 172.30.99.1–254 og spør Zebra-skriverne på port 9100 om navn, modell, DPI, konfigurert utskriftsbredde og etikettlengde. Spørringene er skrivebeskyttet og endrer ikke skriverinnstillinger. Bruk bare på nettverk der du har tillatelse. Skriverporten må være tilgjengelig fra PC-en.

1. Åpne PowerShell på en Windows-PC i samme bedriftsnettverk. 2. Lim inn koden og kjør den. 3. Resultatene kopieres automatisk til utklippstavlen. 4. Lim dem inn under og velg «Importer skriverinfo». Noen skrivere kan mangle enkelte verdier.

Vis PowerShell-koden hvis kopiering ikke fungerer

Om etikettmål: Tallene er skriverens innstilte utskriftsbredde og etikettlengde, ikke nødvendigvis størrelsen på etiketten som faktisk er satt inn. Den siste jobben kan ha endret dem.

4. Skriv ut

Velg hvilke skrivere som skal få etiketten

Hver skriver bruker egen oppløsning og etikettstørrelse. Flere skrivere krever Windows-hjelperen.

1 etikett til én skriver.

Windows-hjelperen brukes automatisk når den kjører. Utskriften skjer da uten nye faner eller ekstra nettleserbekreftelser. Uten hjelper prøves direkte HTTP, som enkelte nettlesere blokkerer.

Sett opp Zebra-status på Windows

Dette er valgfritt. Last ned og kjør den lokale PowerShell-hjelperen på PC-en du skriver ut fra. Hold PowerShell-vinduet åpent mens du bruker appen. Hjelperen lytter kun på 127.0.0.1 på PC-en og kommuniserer med skriverne på 172.30.99.x via port 9100.

Last ned Windows-hjelper (.ps1)

Last ned den korrigerte versjonen (v3). Stopp en gammel hjelper med Ctrl+C og kjør .ps1-filen fra PowerShell dersom bedriftens sikkerhetspolicy tillater det. Ikke lim inn hele koden linje for linje. Test forbindelsen og kontroller at versjon 3 vises.

Reserveutskrift hvis direkte HTTP blir blokkert

Kompatibilitetsmetoden fungerer som tidligere, men kan åpne en fane og vise Chromes sikkerhetsadvarsel. Den brukes aldri automatisk.

Status: Windows-hjelperen kan sjekke Zebra-status. Uten den kan ikke nettleseren bekrefte utskrift. Kontroller etiketten før større opplag. En økt etiketteller er ingen jobbspesifikk bekreftelse hvis andre bruker samme skriver.
